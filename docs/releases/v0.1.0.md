# Android ART Optimizer 0.1.0

First release for Android phones, tablets, and supported Android/Google TVs.

## Install

Download **android-art-optimizer-v0.1.0.apk** and open it on Android. The same APK supports all form factors. On TV, transfer it with a USB drive or trusted file-transfer method and open it using a file manager.

Requires Android 11+ and modern Wireless Debugging. Android 13+ is the intended TV baseline; support is detected at runtime. See the [user guide](https://github.com/daermond/android-art-optimizer/blob/v0.1.0/docs/USER_GUIDE.md).

If you used an early debug test build, note your configured IDs, uninstall it, install this release, and pair again. Later official releases update this version in place.

## Included

- Pairing through notification reply or a QR-linked page on another device.
- Installed-app selection and manual/comma-separated package entry.
- `speed` compilation with real phase/count progress and result verification.
- Saved lists/results, version tracking, reconnect, and actionable recovery.
- TV launcher icon/banner, D-pad focus, and explicit text editing.
- Optional Advanced console with bounded output/history and timeout/cancellation.

Verified on a Samsung Android 16 tablet and a TCL Android 14 TV. TV checks included ART-state-verified compilation, quiet shell commands, timeout recovery, startup reconnect, and D-pad navigation. Android 11/12 devices and iPhone Safari specifically remain unverified.

The APK uses the permanent release certificate. The checksum verifies downloaded assets. The source archive includes tagged app source/build files and pinned ADB/pairing-library sources; it is not needed for installation.
