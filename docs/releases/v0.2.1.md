# Android ART Optimizer 0.2.1

A permanent APK download URL for AFTVnews Downloader and other direct installation tools, plus the dependency and build-tool updates merged since v0.2.0.

## What changed

- Each release now provides identical signed APKs as **android-art-optimizer-v0.2.1.apk** and **android-art-optimizer.apk**. Both are covered by **SHA256SUMS.txt**.
- The permanent [latest APK URL](https://github.com/daermond/android-art-optimizer/releases/latest/download/android-art-optimizer.apk) uses GitHub's latest published production release. Future releases require no change to this URL or a Downloader code created for it.
- The release workflow downloads and verifies both uploaded APKs before publishing, then verifies the permanent URL without authentication when GitHub selects the new release as latest.
- The README documents direct downloading and public repository access. Versioning, signing, source packaging, and GitHub's release-selection behavior are preserved.
- Includes Android Gradle Plugin **9.4.1**, Gradle **9.8.0**, Compose compiler plugin **2.4.20**, Compose BOM **2026.09.00**, and ZXing **3.5.4**, with updated dependency/license records.
- Includes GitHub Actions updates for checkout v7, Java setup v6, artifact upload v7, and Gradle setup v6 using basic caching.

Newly included merged maintenance PRs: **#2, #3, #4, #6, #7, #9, #11, #12, #13**, alongside the permanent-download change in **#17**. Previously released Ethernet ADB and v1 features remain included.

## Install or update

Download **android-art-optimizer.apk** or **android-art-optimizer-v0.2.1.apk**; they are the same APK. Android 11+ is required. The app supports phones, tablets, and compatible Android/Google TVs, using runtime capability detection.

Official v0.1.0/v0.2.0 installations can update in place with the same production signing certificate. Debug/test builds use a different certificate: note your configured package IDs, uninstall the test build, install the official APK, and authorize/pair again. Uninstalling removes the test build's local data; the release does not uninstall anything automatically.

After this release is published and the permanent URL is verified, a numeric Downloader code can be generated through [AFTVnews](https://go.aftvnews.com/) and added to the README. That documentation-only update needs no additional app release. The code must target the permanent URL rather than a version-specific asset.

## Validation and limits

Lint, 31 JVM tests, debug APK assembly, signed release candidate assembly, and 12 release-helper regression tests pass. Workflow validation covers YAML syntax and GitHub Actions semantics. Offline workflow tests verify identical stable/versioned APKs, upload/download checksums, draft reruns, published-release protection, and the permanent download check.

The current debug candidate was installed in place on the TCL C765 (firmware reports TCL Smart TV Pro/G08), Android 14. Shared preferences were preserved exactly during installation, and startup showed **Connected over Ethernet** with verified device identity. The user reported that the app works. This is debug-build device validation; the downloaded production APK's signature, version, checksums, source archive, and permanent URL are verified separately during publication. This release retains the existing connection and optimizer behavior; the broader device limitations remain in the [test plan](https://github.com/daermond/android-art-optimizer/blob/v0.2.1/docs/TEST_PLAN.md).

The release includes both signed APK filenames, **SHA256SUMS.txt**, and the source ZIP with the exact tagged application source and pinned dependency sources. Only one APK is needed for installation.
