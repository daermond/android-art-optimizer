# Android ART Optimizer 0.2.0

Automatic Wi-Fi/Ethernet detection and same-device Ethernet ADB support for compatible Android TVs.

## What changed

- Detects local Wi-Fi and Ethernet connections automatically and reconnects when the link or address changes.
- Supports Ethernet ADB on TVs whose firmware exposes it, sometimes through the **USB debugging** setting in Developer Options. No IP entry or manual connection-mode switch is needed.
- Displays **Connected over Wi-Fi** or **Connected over Ethernet**, the ADB path, and instructions when debugging or authorization is required.
- Keeps the existing Wireless Debugging pairing, notification reply, and QR/web methods.
- Stops interrupted optimization or console work before reconnecting. Commands and batches are never resumed automatically; the app explains when a result may be unknown.

## Install or update

Download **android-art-optimizer-v0.2.0.apk**. The same APK supports phones, tablets, and compatible Android/Google TVs. Android 11+ is required; Android 13+ remains the intended TV baseline, with actual support detected at runtime.

Official v0.1.0 installations can update in place with the same signing certificate, keeping local settings and records. Debug/test builds use a different certificate: note your configured package IDs, uninstall the test build, install the official APK, and authorize/pair again. Uninstalling removes the test build's local data; the release does not uninstall anything automatically.

For Ethernet, connect the cable, enable the TV's **USB debugging** or network debugging option if its firmware supports Ethernet ADB, and approve Android's authorization prompt for ART Optimizer if shown. Standard Ethernet ADB is unencrypted; use a trusted local network. The app only connects to the device's own current Ethernet addresses and does not scan the LAN or enable debugging services.

For Wi-Fi, use the existing **Wireless Debugging → Pair device with pairing code** procedure. See the [user guide](https://github.com/daermond/android-art-optimizer/blob/v0.2.0/docs/USER_GUIDE.md).

## Validation and limits

Verified on a TCL C765 (firmware reports TCL Smart TV Pro/G08), Android 14: automatic Ethernet connection, saved-credential authentication, identity verification, reconnect after relaunch, and automatic return to the existing Wi-Fi TLS connection after the user unplugged Ethernet and enabled Wireless Debugging. Configured apps and optimization records were preserved. Diagnostics detected compilation and ART inspection; no configured app was optimized during these connection tests.

Lint, 31 JVM tests, debug/release builds, and five release-helper regression tests pass. Ethernet support depends on firmware exposing a network ADB listener; a USB debugging setting alone does not guarantee this on every device. Physical Wi-Fi-to-Ethernet return switching, fresh-key authorization/denial, revoked wired authorization, and a network switch during compilation remain unverified on this TV. The existing Kadb handshake timeout limitation remains documented in the architecture.

The release includes the signed APK, **SHA256SUMS.txt**, and a source ZIP containing the exact tagged application source and pinned dependency sources. Only the APK is needed for installation.
